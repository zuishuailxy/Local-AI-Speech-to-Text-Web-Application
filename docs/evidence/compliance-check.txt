# T5.5 合规静态检查

- 日期：2026-10-28
- 范围：前端识别 API、外部依赖/CDN、后端云端 ASR/SDK、运行时网络调用、本地模型加载
- 结论：未发现 Web Speech API、云端 ASR SDK、CDN 依赖或运行时下载路径。



`WhisperModel` 接收 `ASR_MODEL_PATH` 指向的本地目录，不使用模型名触发下载。

## 6. 结论

| 检查项 | 结果 |
| --- | --- |
| 前端 Web Speech API | 未使用 |
| 前端 CDN/外部字体/远程脚本 | 未使用 |
| 后端 OpenAI/Azure/Google 等云端 ASR SDK | 未使用 |
| 运行时 HTTP/socket 调用 | `app/` 内无 |
| 运行时模型下载 | 无；仅 `scripts/download_model.py` |
| 识别模型 | `faster-whisper` + CTranslate2，本地 CPU |

允许的例外：`scripts/download_model.py` 在模型准备阶段访问 HuggingFace/ModelScope；这是题目允许的“提前下载模型”，应用运行和识别过程离线。
