## 已知限制

- Windows CI 是 Windows Server，不是 Windows 11 桌面；真实桌面/麦克风未验证。
- 桌面 Edge 未手动验证；CI 为 headless Edge + 假麦克风。
- 无设备/设备占用为 DevTools 模拟。
- 60 s 计时已验证为 59.8 s（差 0.2 s），未复现旧 57.18 s；不再作为当前缺陷。
- 中文 small 近音字错误；CER 0.18–0.23。
- 语言选择不强制目标脚本。
- 主路径已迁移 AudioWorklet；旧浏览器仅回退 ScriptProcessor，回退路径未实机验证。
- 自动语言检测已实现并手动验证中文/英文/实时 auto；短音频/噪声/混合语言仍可能误判。

## 后续优先级

1. 真实 Windows 11 / 桌面 Edge / 真实麦克风补验（唯一环境阻塞项）。
2. 更大模型或领域数据微调，继续降低中文近音字错误。
3. 噪声/远场/中英混合样本覆盖；AudioWorklet 回退路径实机验证。
4. 可选：`ASR_INITIAL_PROMPT` 领域词按场景开启（默认关闭）。
4. 中文准确率（更大模型/热词）与 CPU 权衡。
5. 自动语言检测、样本覆盖（噪声/远场/混合）、AudioWorklet 回退实机。
