- 环境：macOS arm64 / Apple M1 / Python 3.12.13
- 干净环境：`/tmp/stt-venv-final`（uv 创建，仅安装 `requirements.txt` 的 42 个包）

## 结果解释

- **203 passed**：默认测试全部通过。
- **8 deselected**：5 个 `real_model` + 3 个 `e2e`，默认不执行。
- 干净环境没有安装 Playwright；e2e 模块在 fixture 内延迟导入，默认收集不会失败。
- 没有 `download`、`modelscope`、`huggingface`、`http://`、`https://` 输出；没有创建 `models/`。
- 测试仅走 ASGI `TestClient`、静态文件、纯函数和假引擎，没有启动浏览器，也没有访问麦克风。

## 结论

默认 `python -m pytest -q`：

- 不需要模型权重
- 不需要麦克风
- 不需要下载或外网
- 2–3 秒完成
- 不产生 `models/` 目录或下载缓存

真实模型测试仍需显式 `-m real_model`，浏览器 E2E 仍需显式 `-m e2e` 并安装 Playwright。
