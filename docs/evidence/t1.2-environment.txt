## 3. Windows wheel 交叉下载预检

命令：

```bash
.venv/bin/python -m pip download \
  --only-binary=:all: \
  --platform win_amd64 \
  --python-version 3.12 \
  --implementation cp \
  --abi cp312 \
  -r requirements.txt \
  -d .wheelhouse-check
```

结果：成功，共 41 个 wheel；原始 pip 输出见 `windows-wheels.txt`。

已确认存在 Windows x64 wheel 的关键二进制包：

