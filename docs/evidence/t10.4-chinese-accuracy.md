# T10.4 中文准确率评估

- 日期：2026-10-28
- 样本：`samples/chinese.wav`（12 s）
- baseline：Whisper small / beam 5 / VAD / zh
- 参考：`samples/reference.txt`

## 实验

| 配置 | CER | 推理耗时 | 输出 |
| --- | ---: | ---: | --- |
| 无 prompt | 0.2308 | 3.652 s | 轻轻地我走了,占如我轻轻地来。我轻轻地抓手,做别西天的云彩。那河畔的金牛是西洋中的新娘。 |
| `以下是普通话的句子。` | 0.2308 | 3.043 s | 与 baseline 相同 |
| 领域提示：`以下是普通话语音识别测试，包含：语音识别、实时语音识别、本地语音识别。` | 0.2051 | 3.317 s | `作别` 修正，其余近音字仍在 |

## 结论

- 领域 prompt 有小幅收益（CER 0.2308 → 0.2051），但输出仍存在占如/抓手/金牛/西洋等近音字。
- prompt 可能引入领域词幻觉；未默认启用，也未加入生产配置。
- 更大模型（medium）可能改善，但 CPU/内存成本明显，不在当前优化范围。
- 保持当前默认：无 initial_prompt；用户如需领域词，可后续增加可选配置并在真实音频上复测。

## 验证

- 直接使用 `WhisperModel.transcribe(..., initial_prompt=...)`，同一音频、同一模型参数。
- 未修改参考文本，未掩盖错误。
