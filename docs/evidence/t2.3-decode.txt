## 覆盖点

- 1 秒 WAV：16000 samples、float32、单声道、时长 1.0s
- 5 秒 WAV：80000 samples、时长 5.0s
- 静音 WAV：保留 16000 个零采样，不当作空文件
- WebM/Opus fixture：解码为 16 kHz mono，时长约 1s（T2.6 可复用）
- 损坏字节：InvalidAudioError
- 空文件：InvalidAudioError
- 0 帧 WAV：InvalidAudioError
- 2 秒 WAV + MAX_AUDIO_SECONDS=1：AudioTooLongError (400 / audio_too_long)
- 容器 duration 预检 + 解码样本数二次限制

## 实现

- app/services/audio.py: DecodedAudio / decode_audio
- PyAV AudioResampler: format=flt, layout=mono, rate=16000
- app/errors.py: AudioTooLongError
- tests/fixtures/sample.webm + README（PyAV/libopus 自生成）

## 边界

- 临时文件清理与全路径收口由 T2.4 补充；Windows 端由 GitHub Actions 测试覆盖。
