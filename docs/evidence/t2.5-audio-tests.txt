## 验收矩阵

| 场景 | 输入 | 预期 | 清理 |
| --- | --- | --- | --- |
| 正常 | 1s/5s 生成 WAV | 16 kHz mono float32，时长正确 | 临时目录为空 |
| 静音 | 1s 全零 WAV | 16000 个零采样，不当作空文件；后续 VAD/ASR 返空文本 | 临时目录为空 |
| 空 | 0 字节 WAV | EmptyFileError / 400 | 不创建或清空临时目录 |
| 损坏 | 非音频字节 | InvalidAudioError / 400 | 临时目录为空 |
| 超长 | 2s WAV + 1s 上限 | AudioTooLongError / 400 | 临时目录为空 |
| 超大小 | 1MB+1 `.webm` + 1MB 上限 | FileTooLargeError / 413 | 临时目录为空 |

## 隔离性

- WAV 由标准库 wave/struct 生成，不依赖 `samples/` 或麦克风。
- WebM fixture 是仓库内 1 秒合成 Opus 容器，仅用于格式测试。
- 默认 pytest 不加载模型、不下载权重。
