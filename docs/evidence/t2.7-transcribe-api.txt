## 契约

- `text` / `language` / `duration_seconds` / `processing_seconds` 四个字段；
- `duration_seconds` 来自 PyAV 实际解码；
- `processing_seconds` 从路由开始计时，包含解码与模型调用；
- 有效 WAV/WebM + FakeTranscriber → 200；
- 非法语言 → 400 `invalid_language`；缺 file/language → 422 `validation_error`；
- `.txt` → 415 `unsupported_format`；空文件 → 400 `empty_file`；伪 WAV → 400 `invalid_audio`；
- 超时长 → 400 `audio_too_long`；无模型 → 503 `model_unavailable`；推理异常 → 500 `transcription_failed`；空文本 → 200。

## 实现

- `app/services/transcriber.py`：`Transcriber` Protocol / `TranscriptionResult` / `FakeTranscriber`
- `app/schemas.py`：`TranscriptionResponse`
- `app/api/routes.py`：`POST /api/transcribe`
- `process_audio_upload` 负责解码与临时文件 `finally` 清理
