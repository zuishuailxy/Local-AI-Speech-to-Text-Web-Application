## CLI

```text
python scripts/download_model.py --help
```

支持：

- `--model {tiny,base,small,medium,large-v3}`，默认 small
- `--output`，默认 `models/faster-whisper-<model>`
- `--revision`
- `--source {huggingface,modelscope}`
- `--endpoint`，默认读取 `HF_ENDPOINT`
- `--force`

默认模型：

```text
Systran/faster-whisper-small
```

## 下载与校验

- HuggingFace 使用 `huggingface_hub.snapshot_download`；ModelScope 使用公共 HTTP API。只下载：
  - `model.bin`
  - `config.json`
  - `tokenizer.json`
  - `vocabulary.*`
  - `preprocessor_config.json`（如存在）
- 下载后校验 `model.bin`、`config.json`、`tokenizer.json`、`vocabulary.txt|json`。
- 缺少文件抛 `ModelDownloadError`。
- 下载异常给出镜像/手动放置/网络提示，不静默失败。
- `models/` 已被 `.gitignore` 排除。
