- 日期：2026-10-27

- 状态：脚本与单测完成；真实样本运行待 T3.5 模型下载、T5.1 样本录制后执行

## 用法

```bash
python scripts/verify_asr.py samples/chinese.wav --language zh
python scripts/verify_asr.py samples/english.wav --language en
```

可选：

```bash
python scripts/verify_asr.py audio.webm --language zh --model-path models/faster-whisper-small
```

## 输出

```text
text: ...

duration_seconds: 1.000
processing_seconds: 0.123
```

## 错误提示

模型缺失时：

```text
ERROR: 本地识别模型不存在：<path>。请先运行模型下载脚本。
提示：先运行 python scripts/download_model.py --model small，或通过 --model-path 指定本地模型目录。
```

退出码 1；不会自动下载模型。
