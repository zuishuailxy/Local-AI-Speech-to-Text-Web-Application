## 接线

- `app.main` 的生产 `app` 现在创建 `WhisperTranscriber(Settings.from_env())`。
- `create_app()` 仍可显式注入 Fake/None，测试不加载真实模型。
- `WhisperTranscriber` 构造不加载；首次请求惰性加载。
- `POST /api/transcribe` 走：
  `validate_language → process_audio_upload（解码+finally 清理）→ run_in_threadpool(WhisperTranscriber) → 响应`。
- `processing_seconds` 从路由开始计时，包含解码、首次模型加载和推理；不含下载。

## 观察

- 同一服务连续请求成功，无状态残留。
- 首次中文 4.456s，第二次 3.484s，差值约 0.97s，与单独测得的 small 模型加载约 0.99s 一致。
- 英文 1.674s；与 CLI/基线结果一致。
- 文本与 CLI 输出一致。
- 服务端日志确认 3 次 `POST /api/transcribe` 均 200。
- `model_load_seconds` 日志字段已加入 `WhisperTranscriber`，并由单测 `caplog` 验证；uvicorn 默认日志级别下 INFO 可能不显示，这是日志配置问题，不影响响应。
