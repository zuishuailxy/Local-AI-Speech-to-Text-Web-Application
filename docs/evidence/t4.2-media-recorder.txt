# T4.2 麦克风采集与 MediaRecorder 验证

- 日期：2026-10-27
- 文件：`static/app.js`、`static/index.html`
- 状态：录音核心实现完成；真实麦克风授权/录音待人工验收（T6.1）
- 未实现上传请求（T4.6），因此本轮未产生 Network multipart

## 实现

- 点击 Start 后才调用 `navigator.mediaDevices.getUserMedia`。
- 音频约束：
  - `channelCount: 1`
  - `echoCancellation: true`
  - `noiseSuppression: true`
  - `autoGainControl: true`
- MIME 能力检测顺序：
  1. `audio/webm;codecs=opus`
  2. `audio/webm`
  3. `audio/ogg;codecs=opus`
  4. `audio/ogg`
  5. `audio/mp4`
- `MediaRecorder.start(1000)`，通过 `dataavailable` 分片收集。
- 停止后在 `stop` 事件合并 `Blob`，记录：
  - `blob`
  - 实际 `mimeType`
  - 文件扩展名（webm/ogg/m4a）
  - 字节数
- 暴露 `window.__lastRecording` / `window.recordingApp.getState()` 供 T4.6 上传与浏览器冒烟使用。
- `stop` 后释放所有 `MediaStreamTrack`，避免麦克风占用。
- 空 Blob 显示错误；再次录音重新创建 MediaRecorder。
- 权限/设备错误名称映射为中文提示；完整异常交互在 T4.4。
