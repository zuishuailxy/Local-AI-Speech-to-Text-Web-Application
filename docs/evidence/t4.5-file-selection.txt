# T4.5 文件选择与客户端预检验证

- 日期：2026-10-28
- 文件：`static/app.js`、`static/index.html`
- 浏览器：Review 面板 Chromium
- 说明：本轮只做选择/校验；实际 POST `/api/transcribe` 与结果显示在 T4.6

## 实现

- 文件选择监听 `#file-input` 的 `change`。
- 扩展名白名单与后端保持一致：
  `wav/webm/ogg/oga/mp3/m4a/mp4/flac`
- 客户端校验：
  - 空文件 → 拒绝
  - 超过 10 MB → 拒绝
  - 扩展名不支持 → 拒绝
- 合法文件：
  - 显示 `name · size`
  - 启用 `Upload & Transcribe`
  - 保存 File 供 T4.6 使用
- 非法文件：
  - 清空选择
  - 禁用 Upload
  - 错误面板显示原因
  - 再次选择合法文件可恢复
- 录音/请求进行中禁用 file input，避免状态冲突。
- 客户端校验不能绕过服务端：后端仍执行独立扩展名/大小/解码校验。
