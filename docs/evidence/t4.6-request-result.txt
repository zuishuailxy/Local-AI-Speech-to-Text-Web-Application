# T4.6 请求、状态与结果展示验证

- 日期：2026-10-28
- 文件：`static/app.js`
- 浏览器：Review 面板 Chromium
- 后端：真实 uvicorn + 本地 faster-whisper small
- 说明：上传流程使用真实样本；录音自动提交使用假 MediaRecorder 输出真实 WAV bytes（不伪造识别结果）

## 实现

- 录音停止 / 选择文件后统一调用 `submitAudio(blob, filename)`。
- `FormData`：
  - `file` + 文件名
  - `language` 来自 `#language-select`
- `fetch("/api/transcribe", { method: "POST", body: formData })`
- 请求期间：
  - `requestInFlight` 防重复提交
  - Start/Stop/Upload/语言选择/file input 禁用
  - `#processing-timer` 每 100ms 显示客户端已耗时
  - 状态 `transcribing`
- 成功：
  - 展示 `text / language / duration_seconds / processing_seconds`
  - `#processing-timer` 更新为后端 processing_seconds
  - 结果语言显示“中文（zh）/ English（en）”
  - 音频预览 `URL.createObjectURL(blob)`
  - pipeline 5 步全部 done
  - 状态 success
- 空文本：
  - 结果区提示“未检测到可识别语音”
  - 不视为 500
  - Copy 仍 disabled（T4.7 再实现复制）
- 错误：
  - 解析后端 `detail/code`
  - 错误面板展示，保留最近一次提交供重试
- 录音结束自动提交；60 秒上限提示会保留在请求状态文案中。

## 录音自动提交

```text
lastRecording.mimeType: audio/webm;codecs=opus
lastRecording.extension: webm
lastRecording.size: 384044

lastResult.text: 轻轻地我走了...

```

说明录音结束 → 自动 FormData → 后端识别 → 结果展示链路可用。
