# T5.3 真实上传 API 端到端测试

- 日期：2026-10-28
- 模型：`models/faster-whisper-small`（CPU int8）
- 路径：`TestClient` → FastAPI 路由 → 上传/解码 → `WhisperTranscriber` → JSON
- 新增：`tests/test_e2e_upload.py`、`tests/fixtures/speech-en.webm`、`tests/real_model_support.py`

## 测试内容

- 中英文 `samples/*.wav` 分别上传，断言：
  - HTTP 200
  - 响应字段集合完整
  - `text` 非空
  - `language` 回显请求语言
  - `duration_seconds` 与样本一致（±0.05 s）
  - `processing_seconds > 0`，且不超过客户端观测耗时
  - 中文 CER ≤0.30、汉字占比 ≥0.8；英文 WER ≤0.30、拉丁字母占比 ≥0.8
- 另测 WebM/Opus 语音 fixture，断言 200、非空文本、英文语言、时长约 9 s、WER ≤0.30。

### WebM fixture

`tests/fixtures/speech-en.webm`：

- 由本人录制的 `samples/english.wav` 用 PyAV/libopus 转码，48 kHz mono，48 kbps；
- 时长 8.999 s（容器 9.013 s），55 KB；
- 不是第三方素材，不包含个人信息；
- 与原有 1 秒正弦波 `sample.webm` 区分：后者只用于容器/解码测试，不能用于语音识别断言。

## 边界

- `TestClient` 走完整 ASGI 应用与真实模型，但不经过真实 TCP/浏览器；真实浏览器上传已在 T4.6/T6 单独验证。
- WebM 由 WAV 转码，编码器为 PyAV 自带 libopus；不是浏览器 MediaRecorder 现场生成的容器，但容器/编码路径一致。
- 真实模型测试仅在本地执行；Windows CI 不下载权重，因此这 5 项在 CI 中不会运行。
