# T6.1 Chrome 麦克风录制中文并识别

- 日期：2026-10-28
- 环境：macOS arm64 / Chrome 156.0.8078.49（真实麦克风）
- 服务：`uvicorn app.main:app`，`127.0.0.1:8001`，真实 faster-whisper small
- 语言：中文普通话（zh）
- 截图：`docs/evidence/mic-zh.png`

## 操作

1. Chrome 打开 `http://127.0.0.1:8001`
2. 选择中文普通话（zh）
3. 点击 Start Recording，授予麦克风权限
4. 朗读：`今天天气很好，我们开始测试本地语音识别系统。`
5. 点击 Stop Recording，等待结果

## 最终结果

页面显示：

```text
今天天气很好,我们开始测试本地语音识别系统。
```

- 语言：中文（zh）
- 录音时长：8.2 s（页面显示；服务端 8.160 s）
- 处理耗时：1.71 s
- 文本：简体，与参考文本仅差一个半角逗号
- 忽略标点后 CER：0.0

服务端日志：

```text
request_id=9817a1a83c2c
language=zh
duration_seconds=8.160
processing_seconds=1.712
inference_seconds=1.672
normalization=zhconv-zh-cn
text_chars=22
status=200
```

## 繁转简前后

修复前（设备调试阶段，10.5 s 录音）：

```text
今天天氣很好,我們開始測試本地與陰時別系統。
```

修复后（最终 8.16 s 录音）：

```text
今天天气很好,我们开始测试本地语音识别系统。
```

说明：

- `zhconv` 只统一字形；本次设备调整后模型也正确识别了“语音识别”，没有出现此前的同音字错误。
- 早期 10.5 s 录音还出现过一次空文本（VAD 去除 10.32 s），是设备/输入调试过程，不作为最终结果。
