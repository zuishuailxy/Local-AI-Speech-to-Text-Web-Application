## 失败与修复

### 1. 首次 real-model job 下载失败

- Run `40650671555`，Download real model 失败。
- Check annotation 的最后错误为：
  ```text
  UnicodeEncodeError: 'charmap' codec can't encode characters ...
  ```
- 原因：Windows PowerShell 使用 cp1252，脚本下载成功/失败后打印中文错误时再次抛异常。
- 修复：给 real-model job 设置：
  ```yaml
  env:
    PYTHONUTF8: "1"
    PYTHONIOENCODING: "utf-8"
  ```
- 同时为 ModelScope 失败增加 HuggingFace、hf-mirror 回退与 `::error::` 诊断。

### 2. 修复后

- Run `40651179705` 首次真实模型 + Edge E2E 成功。
- Run `40651812439` 缓存命中并输出运行时细节，成功。

## 限制

- GitHub Actions 是 Windows Server，不是 Windows 11 桌面；真实 Windows 11 麦克风/Edge UI 仍未验证。
- CI 的麦克风是 Playwright 假设备，不是真实麦克风。
- Edge E2E 是 headless，不等于桌面 Edge 手动操作。
- 不能把 CI 成功写成“Windows 11 实机通过”。
